## [P1] dsr-01 — Wide data tables (.var-tbl / .ptbl) lose header/body column alignment in Mobile-mode at wide widths and in the 641–920px band
- **Module/area:** dsr | **Confidence:** medium | **Combo:** 1280xMobile, and 641-920px in both modes
- **Location:** dsr.html — CSS @media(max-width:640px){.var-tbl,.ptbl{display:block;overflow-x:auto}} .var-tbl thead,tbody{display:table;table-layout:fixed} (lines 988-999); shell MOBILE_CSS html.bcc-mobile table{display:block;overflow-x:auto} + uniform @media(max-width:920px){table{display:block}}; tables rendered at renderClosing() var-tbl (line 2353) and renderDashboard() ptbl (line 2709)
- **Defect:** The module only applies its table-repair rules (display:block + thead/tbody{display:table;table-layout:fixed} + sticky first column) inside @media(max-width:640px). But the shell forces table{display:block;overflow-x:auto} in TWO other situations the module does not repair: (a) the uniform CSS @media(max-width:920px) fires on ANY viewport 641–920px in BOTH modes, and (b) MOBILE_CSS html.bcc-mobile table{display:block} fires at 1280 in Mobile display (off-combo). In those cases the table becomes display:block WITHOUT the module's thead/tbody{display:table;table-layout:fixed} realignment, so the header row and body rows are laid out as independent blocks and the Brand/Staff/Opening/Closing/Change columns no longer line up under their headers.
- **Evidence:** .var-tbl,.ptbl{display:block;width:100%;overflow-x:auto;white-space:nowrap} and .var-tbl thead,.ptbl thead,.var-tbl tbody,.ptbl tbody{display:table;width:100%;table-layout:fixed} are BOTH inside `@media (max-width: 640px)` (lines 949, 988-997); no equivalent under html.bcc-mobile or @media(max-width:920px)
- **Impact:** The 4-column Stock Variance table (Closing tab) and the 5-column Staff Performance table (Dashboard) render with headers not aligned over their data columns whenever the viewport is 641–920px (either mode) or in Mobile display on a wide screen. Numbers appear under the wrong header — misreadable audit/variance data.
- **Fix hint:** Widen the module's table-repair block so it also covers the shell's break points: apply the same display:block + thead/tbody{display:table;table-layout:fixed} + sticky-first-col rules under @media(max-width:920px) AND under html.bcc-mobile .var-tbl/.ptbl (not only ≤640px), so alignment is restored wherever the shell forces display:block.
