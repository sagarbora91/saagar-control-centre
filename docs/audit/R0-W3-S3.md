## Scope shipped

- Daily app-private `DATA/SaagarBCC-Backups/` snapshots are passed through
  `SaagarStore.seal()` and stored as device-bound `SBCC1` envelopes.
- Restore content-sniffs bytes and uses `SaagarStore.unseal()` for sealed snapshots.
- Legacy plaintext JSON and the deliberately portable manual Share-to-Drive exports
  remain restorable.
- Existing S1/S2 plaintext DATA snapshots are resealed on upgrade. A verified
  `.plaintext` sidecar protects the source until the sealed replacement reads back.
- A damaged `latest.json` falls back through newest dated snapshots.
- Seal failure remains durability-first: an app-private plaintext snapshot is written,
  logged distinctly, and shown as an owner-visible warning.
- Wrong-device, unavailable-reader and over-size restore failures have distinct messages.
