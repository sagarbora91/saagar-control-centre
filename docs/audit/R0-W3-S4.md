## Scope

- Home shows an explicit red warning when no off-device backup has been confirmed.
- A backup at least four days old is amber; a backup older than seven days is red.
- The action is consistently labelled **Share to Drive** and the copy distinguishes the
  portable backup from the app-private device backup.
- High-risk backup warnings are prioritized into Home's six-card cap.
- Backup alert IDs are stable within a severity. Escalation from amber to red deliberately
  gets a new key so the critical state is not hidden by an earlier amber snooze.
- Red alerts snooze for one day; amber alerts snooze for three days, with matching
  accessible labels and 40 px phone controls.
- Today and Home use aligned recency states.
- Off-device recency is device-local evidence: it is excluded from portable exports,
  blocked on restore, and future timestamps are treated as no valid off-device backup.
- Every share creates a fresh, enriched payload including photo-store, QMS archive and
  evidence snapshots. An unreadable or partial source aborts the export; a cached preview
  is never reused.
- Android only advances the off-device marker after the share sheet returns and the owner
  explicitly confirms that saving/sending outside the phone completed.
- Cancelled, failed and unconfirmed shares leave the marker unchanged and emit terminal
  audit events. Browser downloads update only the manual-backup timestamp.

## S3 close-out hardening folded into the final W3 change

The S4 adversarial pass found edge cases in the already-pushed S3 migration. The final W3
change also:

- fully unseals and JSON-parses a sealed file before deleting its plaintext safety sidecar;
- recovers a header-only or truncated final file from a valid `.plaintext` sidecar;
- verifies sidecar readback byte-for-byte before a sealed current file can be replaced;
- prevents a failed or silently failed sidecar refresh from overwriting the current backup
  with stale plaintext;
- persists the plaintext-fallback warning until both history migration and the current
  sealed write are clean;
- scans current and dated sidecars even when the seal API is unavailable;
- surfaces the warning as a high-priority red Home item and refreshes Home after backup
  status changes;
- distinguishes a missing legacy Documents folder from an enumeration error, never marks
  the purge complete on error, and surfaces the one-time purge on native Home.
